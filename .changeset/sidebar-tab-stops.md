Tab reaches every row of a Sidebar, as it does the links of any menu. Before, the whole navigation was one tab stop, and its other pages could be reached only with the arrow keys, which few people try in a sidebar. The arrow keys still work, and a disabled item is skipped by Tab but still reachable with them. The behaviour comes from a new Tree option, `tabStops="every"`; Tree's default stays one tab stop, the ARIA tree pattern, right for a file tree.
