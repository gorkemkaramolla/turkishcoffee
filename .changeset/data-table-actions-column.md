Add `actionsColumn` to `turkishcoffee/data-table`, the column for a row's actions menu. It is 56px wide and its cell is centred. Its header is read by screen readers only, and its `label` names it in the Columns menu. It cannot be sorted, filtered, resized, hidden, moved or exported. `EllipsisIcon` is now exported from the package root for its trigger.
